## How to apply a code at Vuly's checkout

1. Open the product on [Vuly's site](https://www.vulyplay.com/aff/100/?url=trampoline), choose the size and any accessories, and add it to your cart.
2. In the cart, select **Apply gift/promo code** under the order summary.
3. Type the code, select **Apply**, then confirm in the pop-up.
4. Check the cart before you pay. BOUNCE15 shows in the order summary as a promo code line, and the free speaker or swing appears in the cart marked FREE.

The discount comes off the price shown at checkout, so during a sale it comes off the sale price.

## Vuly promo code questions

### Does the code work on sale items?

Yes. All three codes apply to Vuly's sale prices. During Vuly's November 2026 Black Friday sale, BOUNCE15 took a discount off an Ultra 2 that was already marked down, and BOUNCEFREE added the free swing to a Quest 2.1 on sale.

### Does it work on accessories and spare parts?

Not on their own. Each code needs a qualifying product in the cart: a trampoline, swing set, Slam Pro or monkey bars for BOUNCE15 and BOUNCESURGE, or Quest 2 monkey bars for BOUNCEFREE. With only accessories or spare parts in the cart, Vuly's checkout rejects the code.

Accessories can go in the same order as a qualifying product.

### Can I use two codes?

No. Vuly accepts one code per order. Once a code is applied, the promo code field disappears from the cart, and the checkout pages don't have a second one.

### Why is my code not working?

Vuly's checkout rejects a code when:

- the cart has no qualifying product, for example when it holds only accessories or spare parts
- BOUNCEFREE is entered without Quest 2 monkey bars in the cart
- another code is already on the order
- the qualifying product was removed after the code was applied, in which case Vuly removes the code as well
- the code has a typo or an extra space

If a code still won't apply with a qualifying product in the cart, let us know through the [contact page](/contact/).

### Is there a Black Friday code?

Vuly doesn't have a separate Black Friday code. Its Black Friday prices are already in the cart, and the three codes above apply on top of them. Vuly's 2026 Black Friday sale runs until 27 November, with 20% to 50% off selected trampolines, 30% off swing sets and monkey bars, free delivery, and a free ladder with trampolines.
