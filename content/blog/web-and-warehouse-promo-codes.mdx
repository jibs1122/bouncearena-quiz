## How to apply the code at Web and Warehouse's checkout

1. Add the trampoline or parts to your cart on [Web and Warehouse's site](https://webandwarehouse.com.au/?tracking=6a9550e65374c).
2. Go to the cart and select **Checkout**. The cart page doesn't have a code field.
3. At the top of the checkout, open **Order Summary**, type BOUNCE into the **Coupon code** field and select **Apply**.
4. Check the order summary before you pay. The discount shows as a line marked "Coupon (BOUNCE)" under the subtotal.

## Web and Warehouse promo code questions

### Does the code work on sale items?

Yes. BOUNCE applies to sale prices. It took 5% off a GeeTramp Force 9ft x 14ft in-ground trampoline that was already on sale.

### Does it work on accessories and spare parts?

Yes, including on their own. BOUNCE took 5% off a GeeTramp spring tool in a cart with nothing else in it, and 5% off the whole order when the same tool was added to a trampoline order.

### Can I use two codes?

No. The checkout has one coupon field, and once BOUNCE is applied the field shows only that code, so an order can carry one code.

### Why is my code not working?

The code doesn't apply when:

- it's being entered in the cart, which has no code field (it goes in the coupon field at checkout)
- another code is already on the order
- the code has a typo or an extra space

If BOUNCE still won't apply at checkout, let us know through the [contact page](/contact/).

### Is there a Black Friday code?

Web and Warehouse doesn't have a separate Black Friday code. Its Black Friday prices are already on the products, and BOUNCE takes 5% off on top of them. Our [trampoline deals page](/trampoline-deals-sales/) lists what each Web and Warehouse sale includes.
